# HunarBazaar Login Page

This project is a simple login page for HunarBazaar, designed to connect skilled workers with people in need of services. The login page includes a form for user input, styling for a clean and modern look, and JavaScript functionality for handling user authentication.

## Project Structure

```
hunarbazaar-login
├── src
│   ├── components
│   │   └── Login.html       # HTML structure for the login page
├── styles
│   └── styles.css           # CSS styles for the login page
├── scripts
│   └── login.js             # JavaScript functionality for the login page
└── README.md                # Documentation for the project
```

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd hunarbazaar-login
   ```

3. **Open the `Login.html` file** in your web browser to view the login page.

## Usage

- Enter your email address and password in the respective fields.
- Click the "Sign In" button to simulate a login.
- Use the "Forgot password?" link for password recovery.
- If you don't have an account, click on "Create Account" to sign up.
